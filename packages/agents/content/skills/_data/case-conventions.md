# Case conventions

## Use sentence case, never title case

**ALWAYS use sentence case** for headings, titles, labels, and any text content. Use title case only for proper nouns.
Title case objectively impedes comprehension and creates maintenance burden.

This applies to:

- Document headings and titles
- Ticket titles and descriptions
- Code comments and JSDoc
- UI labels and buttons
- File names and directories

Examples:

- ✅ "Add Chrome extension messaging utilities"
- ❌ "Add Chrome Extension Messaging Utilities"
- ✅ "Enhance Legacy TypeScript types"
- ❌ "Enhanced legacy TypeScript types"
