- **No self-disqualifying findings**: A finding whose own body hedges it out of relevance is noise, not a finding; cut it, don't soften it. Tells: "no action this PR", "not actionable here", "just capturing a thought", "call it out only if X", "would matter once Y". If the condition genuinely holds now, drop the qualifier and state the finding plainly. See the `review-criteria` skill for the full Actionability gate.
