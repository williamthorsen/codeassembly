Speak plainly in practical documentation, in code comments, and in chat. The one carve-out is presentational text, the kind traditionally reviewed by a copy editor, such as marketing and website copy.

Write for a reader who does not share the author's first language, and test each sentence by asking whether that reader parses it on one pass. The test is about structure, not vocabulary: A domain term stays. Use the clearest verb: A file **contains** a section (not "bears" or "carries"), a function **returns** a result (not "the function answers with the result"), a tool **reports** its findings (not "the findings arrive").

A sentence can pass that test and still be **mannered prose**: a figure built for the sentence when a direct statement would do. A term on which this corpus has settled is not one. "a dial worth turning" becomes "a parameter worth varying"; "this point earns its keep" becomes "this point still matters". A figure also adds connotations that the writer did not choose and cannot control. When a literal phrase is available, use it.

A verb that fits any subject and object states no relation between them. "The file carries a section", "the record carries a version", "the change carries a flag": One verb covers three relations and therefore names none of them. Write the verb that names this one: contains, declares, sets. Such a verb passes both tests above, because it is common rather than built for the sentence; therefore, test for it separately.

When a sentence makes data, a file, or a part of a document the subject of an action that an agent or a command performs, the reader cannot tell who acts: "the roots join the recorded ones", "the body reaches the approval gate". A passive that omits an actor that the reader needs hides the actor in the same way. Make the actor the subject. In instructions to an agent, the actor is usually the agent, and the sentence is an imperative: "Show the body to the user at the approval gate." In a document that describes code, the actor is the command or function that acts: "`record` adds the roots to the recorded ones"; an imperative there would give the action to the reader. A subject stays when it performs its verb, animate or not, or when its verb states a relation: A function returns a result, and a file contains a section.

This rule takes precedence over the register of the surrounding documents, this guidance included.
