**Flatten task lists for Markdown and HTML clients.** Before submitting a Jira description or comment through a `contentFormat` tool or an HTML tool, on creation and update alike, convert task-list syntax (`- [ ]` / `- [x]`) to plain `-` bullets. Neither Jira conversion maps it to task items: The brackets are escaped, so each line persists as a bullet reading `\[ \] ...`. The `acli` path is the exception and keeps its checkboxes, because `manage-jira-ticket.mjs` converts task-list syntax to native `taskList` / `taskItem` nodes.
